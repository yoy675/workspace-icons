# workspace-icons

Using different icons for different workspaces on the Cinnamon desktop.

Installation
------------
Install the extension or scripts by running the included installer script:

```bash
./install.sh
```

This repository also contains a Cinnamon extension copy under `Cinnamon Extension/workspace-icons@yoy675` that is structured for submission to the Linux Mint Cinnamon Spices (extensions) system. To install locally, running `./install.sh` is the recommended approach.
